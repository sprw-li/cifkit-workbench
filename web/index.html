    六场景窄闭环与接口说明

    1. 一句话开管线

    POST /api/route 出 TaskSpec 与计划（不执行）；确认后 POST /api/job {kind:"pipeline"}， 再用 EventSource 订阅 GET /api/job/events?id= 实时看日志、步骤条与取消按钮。

    2. 结构修复

    POST /api/op {op:"repair", params:{add_h, disorder, contacts}} → repaired.cif + op.json。

    3. 几何加工

    POST /api/op {op:"geom", params:{standardize, supercell, surface, surface_frame, vacuum, thickness, cluster}}。

    4. 导出与计算输入包

    POST /api/op {op:"convert", params:{formats, bundles, stem, title}}；格式/输入包清单来自 GET /api/bootstrap（离线时读 assets/cif-registry.js）。

    5. 校验 / 特征 / 拓扑证据

    POST /api/op {op:"validate"|"features"|"topology"}；topology 不带 net 时只报证据、不比对。

    6. 库与溯源 / 数据集

    GET /api/runs + GET /api/sources + POST /api/op {op:"dataset"}。

    离线兜底

    所有依赖在 vendor/；GET /api/bootstrap 不可达时页面不白屏， 用 assets/data.js 的预置 mock 渲染，并在卡片上写死「离线演示（无后端）」。

    会出网的路径（CONTRACT §0）

    页面加载与浏览路径零外网请求；唯一会出网的是用户显式点的动作： op=fetch、op=sources_probe、kind=pipeline（cifkit 数据源适配器自身联网）。 GET /api/* 一律无副作用、不联网。

    接入说明 / 改动清单

    本页对上游 EduKit 复用包的**逐文件改动**、app.js 的钩子用法、离线态与自检脚本， 见仓库文件 web/ADAPTATION.md（第三方资产与许可证见 web/SOURCES.md）。 后端静态白名单只托管 /、/assets、/vendor、/components 前缀， 因此根目录的 .md 请用编辑器或静态服务器查看，不在页面上做一个必然 404 的链接。

    接口（CONTRACT.md §2）

    GET  /api/bootstrap /api/runs /api/run?id= /api/artifact /api/sources /api/formats /api/jobs /api/job?id=
GET  /api/job/events?id=        SSE：meta → log/step → （notice/error）→ done
POST /api/route                 {"text"} → {ok, spec, plan, warnings}
POST /api/op                    {"op","params","run","input"} → {ok, run, result, products, argv, elapsed_ms}
POST /api/job                   {"kind","text","spec","plan"} → {ok, job}
POST /api/job/cancel            {"id"} → {ok, job}

    错误一律是 {ok:false, error, message, hint}；页面把三项都显示出来（见 toast 与失败卡片）。

    边界（不做什么）

    • 工作台不实现任何晶体学逻辑：不补氢、不算对称、不切面——一律调 cifkit。
    • 不下载 POTCAR / UPF / 力场；计算输入包是模板，缺件随包说明，不写成「可直接运行」。
    • 拿不到的数据给 null / [] + warnings，绝不编造原子数、真空值、拓扑。
    • 服务只绑 127.0.0.1、无鉴权；写操作全局串行，且只在 runs-dir 下写。
    • 离线演示的数字来自 data.js 预置 mock，不代表任何真实结构结论。
